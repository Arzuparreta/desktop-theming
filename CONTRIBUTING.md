# Delivery workflow

This repository is being built from the ground up. Keep delivery lightweight.

- Work directly on `main` for small changes. Validate, commit and push when
  finished; do not create a branch or pull request for each small change.
- For substantial changes, use a dedicated branch and a pull request with the
  final scope, validation evidence and remaining limitations.
- Push completed work unless the user explicitly requests local-only work.
- Follow any more specific delivery instructions from the current conversation.
